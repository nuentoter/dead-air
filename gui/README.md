# DEAD AIR — GUI development assets

This folder contains the UI work produced during the DEAD AIR GUI design session.

- `prototype_v1/dead_air_ui/`: initial browser UI prototype.
- `production_assets_v1/dead_air_production_assets/`: layers, cutouts, overlays, atlases, and previews.
- `working_v2/dead_air_gui_v2/`: latest playable browser prototype; start with `index.html`.
- `references/`: approved visual master and twelve-concept sheet.
- `build_dead_air_assets.py`: script used to assemble production components.

These are a prototype and extracted art layers, not final painted sprites or a Godot implementation.
The demo simulates signals and records metadata rather than received audio.

## Publishing considerations
The project repository is public; do not publish private story documents or unreleased spoiler ledgers without reviewing them first. Those documents are not included here.
